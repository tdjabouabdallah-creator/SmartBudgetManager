# SmartBudget Manager

## Summary

SmartBudget Manager (SmartBudget_Manager.xlsx) is an Excel workbook.

The workbook enables users to:
- Record monthly income and expenses
- Categorize expenses
- Calculate the monthly balance automatically
- Display a chart of expenses by category
- Receive a warning when the budget limit is exceeded

The workbook contains three worksheets:

- Dashboard: Shows the monthly balance, total income, total expenses, and charts.
- Transactions: Allows the user to enter income and expenses.
- Categories: Contains predefined categories such as Food, Transport, Rent, Health, and Education.

Important note: Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent compatible version is required.

## Getting started

Open the Excel file (ensuring that the required version is used), obtain permission from a high-level administration, review the three worksheets, and edit the values or add classes as needed.
